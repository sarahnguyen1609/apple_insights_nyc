Apple Store Analytics – API & SQL Pipeline Project
Overview:
Developed an end-to-end data analytics pipeline that integrated Apple Store location data with customer sentiment insights from the Yelp API and Webscrape. This project showcased my ability to extract, transform, and analyze data.
Tools & Skills:
Python (Pandas, Requests), SQL (PostgreSQL), Jupyter Notebooks
GitHub Actions for automated workflow
dbt for data transformation
Looker Studio for Visualization
Secrets management via .env and GitHub Secrets
